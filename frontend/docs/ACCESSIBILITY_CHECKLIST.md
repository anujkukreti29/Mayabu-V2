# Accessibility Checklist

Target: WCAG 2.2 AA.

- Semantic header, navigation, main, section, footer, and table structures.
- One logical H1 per primary route and ordered section headings.
- Skip-to-content link and visible keyboard focus.
- Mobile navigation uses a Radix dialog with focus trapping and restoration.
- Background scrolling is blocked while the mobile drawer is open.
- Buttons and icon controls have accessible names and at least 44px targets.
- Search and contact fields have persistent labels or accessible names.
- Validation errors are associated with their fields.
- Verification changes are announced through an ARIA live region.
- Statuses never rely on colour alone.
- Product images use meaningful alt text; absent images use a text fallback.
- Offer tables have headers; mobile offers use readable stacked cards.
- Price-history charts include a textual summary and do not imply prediction.
- Reduced-motion preferences are respected by global styles.
- Keyboard and screen-reader checks remain part of launch testing.
